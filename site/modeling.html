Modeling approach

The first proof of concept changes only the smallest assay-facing part of Nesso. Expensive molecular representations are generated once, audited, cached, and then reused for rapid scaffold-fold experiments.

Frozen representation pathway

  1. Nesso receives the selected prepared ligand state, the fixed 293-residue PXR LBD sequence, and its pinned ESM embedding.
  2. The upstream two-stage refined-pocket inference path runs in evaluation mode for five recycling steps with bf16-mixed Lightning execution.
  3. Temporary forward hooks capture the 384-dimensional input to each pretrained affinity regression head.
  4. The two cached member representations are the fixed input to head-only training. Nesso’s cofolding trunk and affinity modules remain frozen.
Why this boundary is credible

The public Nesso repository is inference-only, and its forward path detaches trunk-derived affinity inputs. Head-only adaptation uses ordinary PyTorch modules without pretending to reproduce the unpublished upstream training procedure.

Primary loss and optimizer

The target is 6 − pEC50. Each batch applies robust Huber loss to the ensemble mean and to both members: 50% on the mean, 25% on member 1, and 25% on member 2. Member terms discourage the heads from drifting in opposite directions while leaving their average unchanged.

Selection without challenge feedback

Hyperparameters are selected only through the five development scaffold folds. Development-fold MAE is primary; Spearman correlation is a required companion and tiebreaker. The affine calibration baseline is fit inside each training fold. A selected configuration is refit on all 4,134 labeled compounds for the median best epoch from cross-validation.

The 513 challenge ligands are final external validation. They do not influence the loss, optimizer, early stopping, calibration, hyperparameter grid, model family, or refit duration. A challenge prediction file is submitted only after the model and file are frozen and explicitly approved.
