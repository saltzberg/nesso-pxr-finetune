## Strict-lane integration contract (published before fitting)

- Module: `experiments.20260906_low_data_followup.code.baselines` (ordinary `importlib.import_module`; no global monkeypatch).
- `METHODS = ("weighted_median", "native_affine", "descriptor_lightgbm_rdkit_mordred")`.
- **Use `descriptor_lightgbm_rdkit_mordred` for the strict panel's descriptor slot.** This is a separately named feasible comparator, not an alias or claimed reconstruction of the historical reduced-feature system.
- `fit_predict(method, train_features, y_train, assay_se_train, test_features, *, config, checkpoint_path, seeds=(42,43,44))` returns original-compatible prediction/selection/audit/state fields.
- `predict_model(model_state, features)` replays without labels/checkpoint. Deterministic non-neural systems fit once; seed arrays are copies, not independent fits or uncertainty.
- `prepare_descriptors(inputs, output_dir=None)` accepts structure/identity columns `record_id`, `canonical_smiles`, optional `row_index` only (caller should subset these explicitly). Returns `(descriptor_array, metadata)`. It computes all RDKit 2D descriptors, all Mordred ignore_3D descriptors, and binary Morgan radius2/2048, chirality false, on each canonical SMILES. No cohort-fitted operation in preparation.
- Feature dictionary key `descriptors` contains the COMPLETE raw block above, including its fingerprint part. Do not concatenate Morgan again. NaN descriptor failures are allowed and imputed within training only. Other allowed original keys remain supported.
- Immutable files will be `artifacts/experiments/low_data_followup_20260906/baselines/features/descriptors.npz` (key `descriptors`) and `descriptor_metadata.json` (ordered record IDs, SMILES, feature names, identities, versions and hashes). `load_descriptors(directory, inputs)` verifies exact identity order and file/array hashes; strict lane should load this cache rather than recompute.
- Baseline-specific constants/grids are exported by the module and frozen in `protocol_baselines.json`; generic caller config controls only floor=.10, inner_folds=3, threads<=2. Native affine uses fit-only weighted squared regression with slope constrained to [0,2], intercept freely fitted; calibration rows are reserved for intervals, not affine fitting. Weighted median uses fit-only inverse-SE weights and lower stable weighted median.

## Historical trace and exact reconstruction boundary

`src/nesso_pxr/comparison.py` supplies scoring and historical inverse-SE times curation weights, not raw features. `scripts/run_publication_comparison.py:445–602` consumes `data/published/reduced_2d_features.parquet`: 15,600 rows, 14,325 numeric columns. It zero-fills invalid values; selects top 1,000 mean inner-CV LightGBM-gain features; fits squared-objective LightGBM, LR .03, 63 leaves, min child 20, lambda 5, up to 5,000 rounds with inner early stopping; final rounds are median inner best iterations. This table is already globally reduced relative to the present low-data subsets and is NOT eligible raw input here.

Actual upstream source found in the historical campaign's `scripts/reduce_feature_universe.py` and `docs/strategies/feature_reduction_v0_1.md`: 32,491 raw deterministic features, variance >.01, correlation connected components at abs(r)>.90, fit on 3,072 historical development compounds with Emax>=.6, select representatives by missing fraction, variance, group/source priority, family and name. Families include atom-pair, Avalon, layered, MACCS, Morgan families, pattern, 2D pharmacophore, RDKit path, SMARTS, topological fingerprints and RDKit/molfeat scalar descriptors. This historical reduction sees many labels/structures unavailable within the present N budget and is forbidden as a cached learned selector.

**Unavailable exact component:** the historical campaign's `data/features/all_ligands/feature_registry.csv` and its unreduced source tables (the entire `data/features` directory is absent), including exact feature family settings/order and prepared-top state table lineage. The published reduced table cannot recover discarded columns or their training-only correlations. Historical prepared-top state selection is not canonical-SMILES feature parity. Existing generator/reducer scripts alone do not establish the missing registry and raw-table identities. No packages/downloads/cloud/API are used to replace missing assets. Exact machine-local source paths are preserved only in `artifacts/experiments/low_data_followup_20260906/baselines/historical_source_trace.md`.

The feasible comparator is therefore named **canonical-SMILES RDKit2D + Mordred2D + Morgan, training-only reduced LightGBM**, method ID `descriptor_lightgbm_rdkit_mordred`. The cached raw block has 3,344 rows × 3,878 columns: 217 RDKit2D, 1,613 Mordred2D and 2,048 Morgan bits. Versions: RDKit 2026.3.2, mordredcommunity 2.0.7, NumPy 2.1.3. The existing cache was reused unchanged. The bounded recipe and source/input hashes are frozen in `protocol_baselines.json`. This broader comparator remains a different feature universe and preparation policy, not restored historical equivalence. All follow-up outcomes are retrospective/hypothesis-generating; no automatic superiority or practical margin is asserted.
