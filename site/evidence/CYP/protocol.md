# Native Nesso score and molecular-weight controls

Created 2026-09-08 UTC. Approved exploratory second case study, frozen before new fits. Historical CYP and PXR results informed this design; reused folds are development evaluations.

## Assay uncertainty decision
The actual TRAIN_inhibition CSV provides each direct pIC50, `_conf_low`, `_conf_high`, and `_std`; its dataset README calls these 95% CI and std. The prepared labels call the mixed-endpoint field `assay_std_or_se`, which does not establish that direct-assay std is a sampling SE. No replicate counts or documented SE conversion, censoring direction, or assay-limit assignment fields are supplied in this CSV. Bounds can be asymmetric. Do not divide interval widths by 3.92 or use std as SE. Freeze equal weights (w=1) for OLS fitting and primary MAE. Retain original bounds/std and audit availability; no invented precision floor or reliability weighting. Error is against reported assay point estimates, not latent true potency.

## Data and models
Only CYP1A2, CYP2C9, CYP2D6, CYP3A4 direct-inhibition pIC50; no +NADPH or TDI outcomes. Use exact matched inhibitor/Nesso cohorts from probabilistic-pair-v1. Parse authoritative training identity SMILES through the historical strict RDKit CXSMILES parser; calculate continuous RDKit Descriptors.MolWt in Da without state changes. Fail rather than silently drop any MW-unparseable row. Retain literal IDs/SMILES and native scalar provenance. Verify native scalar CSV hash against the prior preparation and exact score/SMILES-hash joins.

Nesso s = saved affinity_pred_value, native log10(IC50/uM), lower stronger. Keep s unchanged as fitted input. For unchanged-native error diagnostics ONLY, the single unit/orientation conversion is p_native=6-s; this does not make affinity an assay-calibrated pIC50. CYPMol inhibitor is the exact same-CYP ensemble inhibitor probability, not potency.

Recipes: MW; s; s+MW; s+MW+s*MW; inhibitor; inhibitor+s. Intercepts and unrestricted slopes, unpenalized OLS, training-only population-std scaling of each raw feature (interaction is raw s*MW, then standardized). No grid, clipping, selected threshold or additional features. Reuse historical s/inhibitor/inhibitor+s fits only after exact cohort, role, recipe, scaling and saved-prediction parity. Otherwise stop and declare need for matching refits. Newly fit only the three MW-containing recipes if parity holds. Include unchanged native and training-median diagnostic references.

## Evaluation and uncertainty
Reuse all saved five-fold Butina assignments primary and random secondary, separately. Butina: chiral radius-2 2048-bit Morgan, distance 1-Tanimoto <=0.60, reordering=True, seed 42, whole clusters allocated largest-first. Canonical identities remain within folds; cross-fold close neighbors can remain. Report full and <215 / >=215 Da subgroup pooled and fold MAE, Spearman, signed bias (prediction-observation), coverage, and native-relative individual loss changes. The 215 Da threshold is transferred descriptive, not tuned. No potency cutoff is justified as a universal direct-assay active boundary in the audited source; omit PXR's pIC50=4 strata rather than import it.

Paired contrasts: each fitted control versus unchanged native; s+MW minus s; interaction minus additive; additive/interaction minus MW and inhibitor; inhibitor+s minus inhibitor. 2000 whole observed Butina-group bootstrap samples, seed 42, row-weighted paired mean error differences, full and MW strata, common draws within cell. Preserve draws. Intervals condition on saved fits and fixed splits, not retraining, and have no multiplicity correction. Subgroup intervals resample represented chemical groups and are descriptive.

## Design and execution
Compact local HTML generated from canonical README plus two real figures: endpoint MAE dot plot (absolute unweighted pIC50 error; clearly distinguish native from fitted sources), and low-MW native-relative MAE changes with paired intervals and counts. Stable endpoint/model order, zero references on deltas, no performance-selected models. Full downloadable metrics, predictions, fits, roles and provenance. CPU <=4 threads, no GPU/inference/cloud/blinded-label use. Save protocol/hash binding before fits. Independent QR reconstruction, source/native/MW/role replay, metrics and bootstrap checks; refuse existing output root on fitting invocation.
