Building a PXR activity model from Nesso-1

This project uses Nesso-1 as a starting point for predicting PXR activity. Most of Nesso stays fixed. We will train two small prediction models on measured PXR data.

Where things stand

Nesso is processing all 4,134 training compounds and saving two compact descriptions of each one. Model training will start when that work is done.

4,134labeled PXR compounds
3,344compounds for model development
790compounds held back for one check
513challenge compounds reserved for the end

The plan

  1. Use Nesso-1 to describe each molecule with two sets of 384 numbers.
  2. Train the two small prediction models on the PXR measurements.
  3. Choose training settings with five groups built from chemical structure.
  4. Check the chosen model once on the 790 compounds set aside for that purpose.
  5. Train on all labeled compounds and make predictions for the 513-compound challenge set.
