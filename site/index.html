Can Nesso-1 be adapted to functional PXR potency?

This study freezes Nesso’s cofolding representation and asks whether small, assay-specific regression heads improve PXR pEC50 prediction over frozen Nesso and fold-local calibration.

Current state

Full frozen-feature extraction launched at approximately 2026-08-06 19:11 UTC for all 4,134 compounds on an NVIDIA GeForce RTX 5070 Ti. It uses the exact validated Lightning prediction path and is estimated to take 4.5–5 hours. Head training has not started, so there is not yet a loss curve or held-out training result.

What is fixed

  1. Primary population: all 4,134 curated dose-response compounds. The earlier Emax ≥ 0.6 subset is a sensitivity analysis, not the primary cohort.
  2. Leakage control: five-fold scaffold-aware splits use Morgan radius-2 fingerprints, Butina clustering at Tanimoto 0.60, and intact Bemis–Murcko scaffold groups.
  3. Adaptation scope: train only Nesso’s two pretrained regression MLPs over cached 384-dimensional representations; the cofolding trunk remains frozen.
  4. External test: the 513-ligand activity challenge set is final validation only and cannot tune hyperparameters, stopping, calibration, or model choice.
