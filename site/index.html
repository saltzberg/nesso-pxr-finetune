Fine-tuning Nesso helps, but a 2D model remains stronger

This project tests whether PXR measurements can improve Nesso-1's activity predictions and whether the adapted model competes with a conventional molecular model. The answer is yes to the first question and no to the second.

Main result

In a matched nested comparison on 3,344 compounds, fine-tuned Nesso reached an average error of 0.633 pEC50, improved from 0.915 for unchanged Nesso. A 2D LightGBM model reached 0.516. The same ordering appears on the historical check set and the public challenge data.

Evidence status

The 513 challenge labels were public before this analysis. Those results are retrospective external-dataset evidence, not a temporal blind test.

What the project now shows

  1. Fine-tuning transfers useful PXR signal into Nesso's two prediction heads.
  2. A training-fold mean confirms that both learned models contain substantial signal.
  3. Nested chemical-family cross-validation keeps each outer test fold out of model choice and stopping.
  4. The established 2D model is more accurate and orders compounds better than fine-tuned Nesso.
  5. The models make related mistakes: signed residual correlations are 0.77–0.82, although Nesso is better for about 39–40% of individual compounds.
  6. Both models compress the highly active tail and rarely predict pEC50 above 6.
