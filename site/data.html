Primary endpoint

The supervised endpoint is functional cellular pEC50, with its reported standard error retained for prespecified uncertainty-weighted ablations. Training uses the curated weighted artifact, while the raw 4,139-row source remains the immutable label audit source. Five named hard exclusions leave 4,134 compounds.

Nesso’s documented scale is aligned numerically as target = 6 − pEC50; reported uncertainty is unchanged in magnitude. This transformation does not claim that functional EC50 and biochemical IC50 are biologically equivalent.

Prepared chemistry

The baseline uses one selected prepared protonation/tautomer state per original ligand from the existing top-state map. Alternate states are not counted as independent labels and are reserved for a later ablation.
