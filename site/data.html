Data used in this project

Compound selection and evidence cohorts

The modeling dataset has one curated PXR dose-response measurement for each of 4,134 compounds. A separate set of 513 challenge compounds now has public outcomes used only for retrospective evaluation.

What each row contains

  • A molecule: one cleaned structure linked to the original compound ID.
  • A measured value: pEC50 from the PXR dose-response assay.
  • An uncertainty: how precise the reported measurement is.
  • A quality score: a value that can give cleaner measurements more weight during training.
  • A role: development or the historical check set; challenge compounds remain a separate external cohort.

Chemical preparation

Each compound uses one prepared version of its structure. Other versions of the same compound are not counted as new measurements. The structure used by Nesso stays tied to the source compound ID.

How development compounds are divided

The 3,344 development compounds are split into five groups of 668 or 669. Molecules with the same core chemical framework stay in the same group. Close chemical neighbors are also kept together. This makes each outer test group less like the molecules used to train its model.

Retrospective evidence

The challenge outcomes were not used to train either evaluated prediction set, but they were public before this analysis. The challenge comparison is therefore not a temporal blind test.

Data outside this analysis

Single-concentration measurements and the PXR-null counter assay are not part of this first model comparison. They remain available for later work.

The historical 2D challenge comparator also includes curated ChEMBL PXR measurements. Its challenge result is an established external comparator, not the exact model used in the matched nested development analysis.
